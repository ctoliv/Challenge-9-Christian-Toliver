# Challenge-9-Christian-Toliver
1. The decorative statue model was the easiest to integrate because it only needed to be imported, positioned, and scaled to fit naturally in the courtyard.

2. One challenge I encountered was getting the imported models to the correct size and position. Some models were much larger than expected, so I had to adjust their scale and placement several times. I also had some difficulty getting the collision detection to behave correctly with the imported collision model.

3. Collision detection improved the realism of the scene because it made the player interact with the environment instead of being able to move through every object. It helped make the courtyard feel more like an actual game environment.

4. If I had another hour, I would add more interactive objects to the courtyard, such as additional obstacles, collectible items, or another animated character.

5. A decorative model is mainly used to improve the appearance of the scene and does not need to respond to the player. An interactive model has some type of behavior or interaction, such as moving, playing an animation, blocking the player, or responding to controls.
